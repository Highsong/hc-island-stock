---
name: 模块隔离规则
description: 股票分析和我的投资是两个独立模块，不做级联修改
type: feedback
---

**规则：股票分析模块 和 我的投资模块 完全独立，互不影响。**

- `app_new.py`（股票分析）和 `portfolio_view.py`（我的投资）是两个独立页面
- 它们各自独立调用数据源，不共享数据源管理器实例
- 修复一个模块的 bug 时，不得修改另一个模块的代码
- 两个模块的雪球 Cookie 依赖是独立的（虽然用同一个 cookie 文件，但调用逻辑独立）
- **Why:** 之前出现过修复股票分析时改了数据源管理器，导致我的投资模块也受影响
- **How to apply:** 任何修复只针对报错的模块，修改前确认影响范围
