# 茅台年报分析系统

基于Streamlit的贵州茅台年报智能分析工具，支持财务数据分析、趋势可视化和智能评语生成。

## ✨ 核心功能

### 📊 数据分析
- **PDF智能解析**: 自动提取年报中的财务数据
- **10年历史分析**: 支持2016-2025年完整财务数据分析
- **季度深度分析**: 近3年季度业绩趋势分析
- **多维度指标**: 盈利能力、成长性、流动性、杠杆水平全面分析

### 📈 可视化展示
- **交互式图表**: Plotly动态图表，支持缩放、筛选
- **多种图表类型**: 折线图、柱状图、饼图、瀑布图、双轴图
- **专业配色方案**: 茅台主题色彩，视觉体验优秀
- **一键导出**: 支持PNG、PDF、Excel格式导出

### 💡 智能分析
- **自动评语生成**: 基于财务指标的智能分析洞察
- **趋势识别**: 自动识别财务趋势和异常点
- **风险评估**: 综合评估公司财务健康状况
- **投资建议**: 提供基于数据的投资参考意见

## 🚀 快速开始

### 环境要求
- Python 3.11+
- 足够的磁盘空间存储PDF文件

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd moutai-analysis
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **准备数据**
- 将茅台年报PDF文件放入 `data/raw_pdfs/` 目录
- 支持的文件命名格式：`02MT2025年年报.pdf`

4. **启动应用**
```bash
streamlit run src/app.py
```

5. **访问应用**
- 打开浏览器访问: `http://localhost:8501`

## 🎯 使用说明

### 主界面功能

1. **侧边栏控制**
   - 年份选择：支持多选进行对比分析
   - 分析类型：单年分析、多年趋势、季度分析、综合报告
   - 指标筛选：选择关注的财务指标类别
   - 导出设置：选择图表导出格式

2. **四个主要标签页**
   - **财务概览**: 关键指标卡片和核心图表
   - **趋势分析**: 多年数据趋势对比
   - **季度分析**: 季度业绩和季节性分析
   - **综合报告**: 完整的分析报告

### 交互功能

- **图表交互**: 鼠标悬停查看详细数据，拖拽缩放
- **筛选功能**: 实时筛选不同年份和指标
- **导出功能**: 一键导出图表和报告
- **响应式设计**: 适配不同屏幕尺寸

## 🔄 数据更新

### 自动更新
1. 将新的年报PDF文件复制到 `data/raw_pdfs/` 目录
2. 系统自动检测新文件
3. 点击"刷新数据"按钮更新分析

### 手动更新
```python
# 在应用中点击"重新处理数据"按钮
# 或重启Streamlit应用
streamlit run src/app.py
```

## 📊 分析指标

### 盈利能力指标
- 净利润率、毛利率、ROE、ROA
- 成本收入比、费用率

### 成长性指标
- 营业收入增长率、净利润增长率
- 复合增长率、年均增长率

### 流动性指标
- 流动比率、速动比率
- 现金比率、营运资金

### 杠杆指标
- 资产负债率、权益乘数
- 利息保障倍数

### 现金流量指标
- 经营现金流、自由现金流
- 现金流增长率

## 📈 示例分析

### 财务健康度评分
- 9-7分: 优秀，各项指标表现出色
- 6-4分: 良好，整体稳健但有改善空间
- 3-1分: 关注，部分指标需要重点关注

### 投资价值评估
- **强烈推荐**: 盈利能力>25%，增长率>20%，流动性>2.0
- **推荐**: 盈利能力>15%，增长率>5%，流动性>1.0
- **中性**: 指标表现一般，建议观望
- **谨慎**: 多项指标低于健康水平
