# 📊 通用股票财务分析系统

基于Streamlit的通用股票财务分析工具，支持A股和港股数据分析、趋势可视化和智能分析洞察。

## ✨ 核心功能

### 📊 数据分析
- **API数据获取**: 基于AKshare API获取实时财务数据
- **多股票支持**: 支持A股和港股分析
- **多周期分析**: 支持年度、半年度、季度数据分析
- **智能缓存**: 自动缓存数据，提高访问速度
- **多维度指标**: 盈利能力、成长性、流动性、杠杆水平全面分析

### 📈 可视化展示
- **交互式图表**: Plotly动态图表，支持缩放、筛选
- **多种图表类型**: 折线图、柱状图、饼图、瀑布图、双轴图
- **专业配色方案**: 企业财务分析主题色彩，视觉体验优秀
- **一键导出**: 支持PNG、PDF、Excel格式导出

### 💡 智能分析
- **自动评语生成**: 基于财务指标的智能分析洞察
- **趋势识别**: 自动识别财务趋势和异常点
- **风险评估**: 综合评估公司财务健康状况
- **投资建议**: 提供基于数据的投资参考意见

## 🚀 快速开始

### 环境要求
- Python 3.11+
- 网络连接（用于获取股票数据）

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd stock-analysis
```

2. **安装依赖**
```bash
pip install -r requirements.txt
pip install akshare
```

3. **启动应用**
```bash
streamlit run src/app_new.py
```

4. **访问应用**
- 打开浏览器访问: `http://localhost:8501`

5. **开始分析**
- 输入股票代码（如：000858、600519、0700.HK）
- 选择数据周期和分析范围
- 点击"开始分析"按钮

## 🎯 使用说明

### 主界面功能

1. **股票选择区域**
   - 股票代码输入：支持A股和港股代码
   - 数据周期选择：年度、半年度、季度
   - 年份范围设置：自定义分析时间范围
   - 分析按钮：开始数据分析

2. **四个主要标签页**
   - **财务概览**: 关键指标卡片和核心图表
   - **趋势分析**: 多年数据趋势对比
   - **周期分析**: 季度/半年度业绩分析
   - **综合报告**: 完整的分析报告

### 交互功能

- **图表交互**: 鼠标悬停查看详细数据，拖拽缩放
- **筛选功能**: 实时筛选不同年份和指标
- **导出功能**: 一键导出图表和报告
- **响应式设计**: 适配不同屏幕尺寸

## 🔄 数据更新

### 自动缓存更新
- 数据自动缓存7天
- 过期后自动重新获取最新数据
- 网络异常时使用缓存数据

### 手动清理缓存
```bash
# 删除缓存目录
rm -rf data/cache/

# 或在应用中重新分析
streamlit run src/app_new.py
```

## 📊 分析指标

### 盈利能力指标
- 净利润率、毛利率、ROE、ROA
- 成本收入比、费用率

### 成长性指标
- 营业收入增长率、净利润增长率
- 复合增长率、年均增长率

### 流动性指标
- 流动比率、速动比率
- 现金比率、营运资金

### 杠杆指标
- 资产负债率、权益乘数
- 利息保障倍数

### 现金流量指标
- 经营现金流、自由现金流
- 现金流增长率

## 📈 示例分析

### 财务健康度评分
- 9-7分: 优秀，各项指标表现出色
- 6-4分: 良好，整体稳健但有改善空间
- 3-1分: 关注，部分指标需要重点关注

### 投资价值评估
- **强烈推荐**: 盈利能力>25%，增长率>20%，流动性>2.0
- **推荐**: 盈利能力>15%，增长率>5%，流动性>1.0
- **中性**: 指标表现一般，建议观望
- **谨慎**: 多项指标低于健康水平
