# 用户指南

## 系统介绍

本系统提供贵州茅台年报的全面分析，包括：

- 财务业绩分析
- 资产负债分析
- 现金流量分析
- 趋势对比分析
- 智能评语生成

## 使用说明

### 1. 启动系统
```bash
streamlit run src/app.py
```

### 2. 导航功能
- **主页**: 概览关键指标
- **财务分析**: 详细财务数据
- **趋势分析**: 多年趋势对比
- **季度分析**: 季度业绩分析
- **综合报告**: 完整分析报告

### 3. 交互功能
- 使用侧边栏筛选年份
- 点击图表查看详细数据
- 导出图表和报告

## 数据更新

1. 将新年报PDF复制到 `data/raw_pdfs/`
2. 重启应用或点击"更新数据"按钮
3. 系统自动处理并更新分析
